# Retro Review Policy

Status: `draft_round_001`

Retro-review is mandatory when:

- the workflow itself changes
- old reviewer conclusions were produced under a prior contract
- old program overlays are still influencing current work

Retro-review must answer:

1. what old rule set applied
2. what evidence it produced
3. what is still valid
4. what must be re-judged under the new workflow
