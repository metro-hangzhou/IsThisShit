# First Principles Law

Status: `draft_round_003`

## Core Rule

Every unit in the workflow must retain the right and the duty to challenge wasteful process from first principles.

## Applies To

- reviewer
- explorer
- worker
- main agent
- subagents

## Required Behavior

- challenge needless waiting when evidence already resolves the issue
- challenge local rules that conflict with the actual system goal
- prefer direct evidence-level judgment over ritualized timeout or bureaucracy
- explain why a shortcut is correct, not merely that it is faster
- always ask:
  - what is the real goal
  - why does this path exist
  - has this path drifted from serving the goal into serving itself
  - is there a shorter, more reliable, lower-cost correct path
- preserve causal-trace thinking:
  - identify the real causal chain behind wasteful process
  - identify where path bloat, wait bloat, and hierarchy bloat come from
- preserve decision thinking:
  - once evidence is sufficient, decide
  - do not confuse “wait longer” with “think harder”

## Anti-Bullshit Clause

If the system can already judge an asset, state, or design outcome from evidence, then forcing it through a meaningless 30-second timeout or a long hierarchy hop is considered workflow failure, not acceptable caution.

## Clarification

`timeout` is only an example, not the whole law.

This law opposes any process where the system could already decide correctly, yet still keeps wasting time on ritual, waiting, or pointless indirection.
