# AGENTs.napcat_truth_map_surface

## Scope

Analyze NapCat truth sources in:

- `NapCat/`
- `NapCatQQ/`
- fast plugin source
- any docs/README/configs that actually exist here

## Goal

Produce a truth map of:

- stable evidence fields
- stable route semantics
- weak signals
- runtime phenomena that are not contractual

The output must explain what exporter evidence can legitimately be derived from NapCat and what cannot.

## Do Not

- summarize unrelated UI/build/system code
- drift into general node_modules content
