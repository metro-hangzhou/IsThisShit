# Common Track Workflow Output Contract

Each round must produce:

1. `source_digest.md`
2. `review_input.md`
3. `review_questions.md`
4. `review_blockers.json`
5. `resolved_truth_sources.json`
6. `truth_source_usage.json`
7. `worker_response_round_n.md`
8. `user_review_checkpoint_round_n.md`

Optional supporting artifacts:

- `topology_map.md`
- `role_conflict_map.md`
- `archive_scope.md`
- `redirect_policy.md`
- `round_lifecycle_draft.md`
- `task_dispatch_plan.md`
- `subagents_first_policy.md`
- `main_agent_role_and_model_policy.md`
