# 搬史报告复审检查清单

对应 canonical 英文文件：

- [benshi_review_checklist.md](benshi_review_checklist.md)

## 用途

这是一份 review checklist，不是报告本身。

它的作用是帮助复审时快速检查：

- 报告看对了什么
- 过推了什么
- 漏了什么
- 哪些维度已经够稳定
- 哪些仍然太早

## 当前 checklist 关注面

### 1. Report noticed correctly

- 稳定主题
- 互动模式
- 参与者软角色

### 2. Overgeneralizations

- 稀疏文本上的过推
- missing media 上的脑补
- 应保持观察态却被写成结论态的地方

### 3. Missed dimensions

- 文本/上下文信号
- reply / forward 结构
- share / system / media-gap 信号

### 4. Evidence quality

- direct observed evidence
- context-only inference
- unknown / missing-media gaps

### 5. Future schema candidates

- 哪些稳定 enough
- 哪些还太早

## 当前角色

在 cleaned slice 里，它被归入：

- `reviews`

因为它是 review 工具，不是长期规则总法。
